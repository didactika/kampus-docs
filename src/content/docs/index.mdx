## What makes Kampus different

<CardGrid>
  <Card title="Everything by scope" icon="setting">
    Settings, terms, custom fields, layouts and themes change per campus, category, course or section.
  </Card>
  <Card title="Safe plugins" icon="puzzle">
    Plugins run sandboxed and get only what an administrator grants them.
  </Card>
  <Card title="Upgrades in one step" icon="rocket">
    Any supported release upgrades straight to the latest one.
  </Card>
  <Card title="Explainable records" icon="document">
    Every grade has its history, and hidden grades stay hidden everywhere.
  </Card>
</CardGrid>
