## Uploading

You upload files where Kampus asks for them: your profile picture, the attachments of a message, and the files of the activities that take them. Every file belongs to what you attach it to.

An upload can be refused, and Kampus tells you why:

| Reason | What to do |
| --- | --- |
| The file is too large or of a type the place does not take | Choose another file or reduce its size |
| There is no space left in the place or in your own allowance | Remove files you no longer need, or ask an administrator |
| The file contains malware | Nothing is kept; check the file on your device |

## Opening

You can open a file when you may see what it belongs to, and nobody else can. The link Kampus gives you lasts a few minutes, so a link copied into a message stops working soon after. Pictures show a small preview first. Files that could run in a browser, such as web pages, are always downloaded instead of opened inside Kampus.
