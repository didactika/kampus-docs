| 0.1.0 | In development on `release/0.1.0` | — |

Kampus follows Semantic Versioning. The latest minor version of the current major version, and the last minor version of the previous major version, receive security and bug fixes. Each release states when support ends for the versions it replaces.

This documentation is versioned with Kampus: the `release/X.Y.Z` branch of the documentation describes Kampus `X.Y.Z`.
