These pages are generated from the declarations of the modules of the version you read, so they list exactly what that version has. They are the place to look up a name you met in a guide, in the API or in a log.

| Page | What it lists |
| --- | --- |
| [Permissions](/reference/permissions/) | Every permission, its risks, the lowest scope it applies to and the roles that grant it |
| [Settings](/reference/settings/) | Every setting, what it accepts, where it can be set and who may change it |
| [Features and terms](/reference/features-and-terms/) | The features a scope turns on or off, and the terms a campus can rename |
| [Events](/reference/events/) | Every event, its fields and whether it is audited |
| [Notifications](/reference/notifications/) | Every type of notification and its channels |
| [Jobs](/reference/jobs/) | Every background job and its schedule |

The API has its own description, served by every installation (see [the API description](/integrators/api-description/)).
